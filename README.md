# Artificial Intelligence & Algorithmic Foundations
### Graduate Technical Portfolio | Master of Science in AI (May 2026)

This repository serves as a comprehensive technical evidence locker for my Master’s degree research and implementation projects. It spans the full spectrum of modern AI—from the mathematical first principles of optimization to the deployment of generative diffusion models and scalable big data architectures.

---

## 📁 Repository Structure

### 🛰️ [Deep-Learning-and-Signal-Processing](./Deep-Learning-and-Signal-Processing)
*High-fidelity signal analysis for aerospace and defense.*
* **Spatio-Temporal Physical Forecasting:** Multi-step forecasting using SVD for EOF dimensionality reduction and PyTorch (RNN, LSTM, Transformer).
* **Underwater Acoustic Diffusion:** Using DDPM Diffusion Models and VAEs to generate synthetic sonar/ship data to train robust classifiers.
* **Custom Transformer Architectures:** Implementation of attention-based models for acoustic signature classification.

### 👁️ [Computer-Vision](./Computer-Vision)
*Advanced multi-task and regularized image processing.*
* **Multi-Task Facial Analysis:** A shared-backbone CNN that simultaneously predicts age (regression) and gender (classification) using custom batch generators.
* **Regularization Ablation Study:** 10-fold cross-validation analysis of Batch Normalization and Dropout impact on model generalization.
* **MNIST Heuristic Classification:** From-scratch feature engineering and threshold-based decision boundaries.

### 📊 [Applied-Machine-Learning](./Applied-Machine-Learning)
*End-to-end pipelines and mathematical implementations from first principles.*
* **Marketing ML Pipeline:** End-to-end pipeline featuring Power Transformers, GMM/KMeans comparison, and feature consensus engines.
* **Clinical Severity Regression:** Ridge, Lasso, and Kernel Ridge Regression analysis for biomedical heart failure prediction.
* **Manual PCA & Mathematical Classifiers:** From-scratch Eigendecomposition and Minimum Distance Classifiers (NumPy only).
* **Scratch-Built Bayesian Classifiers:** Implementation of Gaussian Naive Bayes from probability density functions.
* **Gradient Descent Optimizer:** Custom GD engine with manual partial derivative calculations for Rosenbrock topologies.

### 🕸️ [Graph-Analysis-and-Big-Data](./Applied-Machine-Learning)
*Scalable network science and distributed computing.*
* **PySpark Big Data Pipeline:** Distributed linear regression and clustering on Spotify collaboration networks using Spark MLlib.
* **Twitter Community Detection:** Girvan-Newman edge-betweenness vs. Louvain modularity optimization.
* **Link Prediction:** Topological feature engineering (Adamic-Adar, Jaccard) for social network edge prediction.

### 🤖 [Classical-AI-and-Search](./Search-Algorithms)
*Optimization and heuristic reasoning.*
* **Informed Search:** A* Pathfinding and Utility-Maximizing agents.
* **Stochastic Optimization:** Simulated Annealing for the N-Queens constraint satisfaction problem.
* **Reinforcement Learning:** Q-Learning and Epsilon-Greedy Multi-Armed Bandit implementations.
